## Latest Preview: V5

- [Datascape](https://andreapickensnz.github.io/drss-4019-general-pest-inspection/DRSS-4019%20General%20Pest%20Inspection%20-%20Datascape%20-%20v5.html)

V4 follows Survey-5 and Halema's 10 November clarification: standard Survey Date/Time, no custom Date of Inspection or Link to data collection question. External links can be added to the Activity Description to appear on the Booking.

V5 retains that behaviour and updates Data collected using to the Survey-6 choices: S123, Quick Capture, Fieldmaps, and Notebook/Datasheets. Both prototypes link to their V5 counterpart. V4 pages remain available at their existing URLs.

Run checks with `node --test controls.test.mjs`.
